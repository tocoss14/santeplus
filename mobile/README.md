# SantéPlus Mobile (squelette)

Application mobile native (React Native / Expo) — squelette initial.

## Démarrage
```
cd mobile
npm install
npx expo start
```

## Fonctionnalités prévues (Phase 2)
- Notifications push (rappels cotisation, validation remboursement)
- Géolocalisation native du réseau de soins
- Carte QR native (stockage sécurisé, hors ligne)
- Authentification biométrique (TouchID/FaceID)
- Téléversement de photos optimisé (OCR local)
- Chat support
- Tableau de bord personnel
