ANOMALIE A -- HIGH

Une pharmacie peut actuellement créer une ordonnance.

ANOMALIE B -- HIGH

Un bénéficiaire de type CHILD avec une date de naissance future, par exemple 2030, peut être accepté.

Le contrôle childMaxAge ne couvre pas l'interdiction d'une date de naissance future.

ANOMALIE C -- HIGH

Après épuisement du CTS, certaines confirmations de tiers payant continuent de créer des claims
 CONFIRMED , alors que recordEngagement échoue silencieusement.

Deux problèmes structurels ont été identifiés :

   batch-invoices  THIRD_PARTY
   claims  THIRDPARTY

Cette différence empêche notamment la récupération correcte des claims pour les factures groupées.

37. CRITÈRES DE « FIXED »

Une anomalie ne peut être déclarée :

FIXED

que si :

      1. la cause racine est corrigée ;
      2. le test qui reproduisait le problème échoue désormais comme attendu ;
      3. le test positif correspondant fonctionne toujours ;
      4. un test automatisé de régression existe ;
      5. les API et DB sont cohérentes ;
      6. aucun contournement frontend ne permet de reproduire le problème ;
      7. les tests globaux ne régressent pas.
